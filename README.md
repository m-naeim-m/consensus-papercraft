# استودیو نگارش مقاله با هوش مصنوعی کانسنسوس (Consensus PaperCraft Studio)

این نرم‌افزار یک سیستم جامع و هوشمند برای پژوهشگران است که با اتصال به **API رسمی پایگاه Consensus.app** (شامل بیش از ۴۰۰ میلیون مقاله داوری‌شده علمی)، امکان کاوش شواهد پژوهشی، ساخت ماتریس ادبیات و نگارش خودکار و ساختاریافته بخش‌های مختلف مقاله دانشگاهی را فراهم می‌آورد.

---

## ویژگی‌های اصلی سیستم

### ۱. توزیع بار هوشمند بین چندین کلید (Load Balancing & Round-Robin)
- **پشتیبانی از چندین اکانت:** شما می‌توانید کلیدهای API مربوط به ۶ اکانت (یا بیشتر) کانسنسوس را به سیستم معرفی کنید.
- **توزیع چرخی (Round-Robin):** درخواست‌ها به شکل متناوب بین اکانت‌های فعال پخش می‌شوند تا از سهمیه ماهانه هر اکانت به شکل بهینه و متوازن استفاده شود.

### ۲. سوییچ خودکار در صورت خطا و ریت‌لیمیت (Smart Failover)
- **مدیریت ریت‌لیمیت (HTTP 429):** اگر کلیدی به سقف درخواست در ثانیه یا ریت‌لیمیت برخورد کند، سیستم به شکل خودکار کلید را به مدت ۶۰ ثانیه وارد استراحت (Cooldown) کرده و همان درخواست را **بدون وقفه و شفاف با کلید سالم بعدی** اجرا می‌نماید. پس از پایان زمان انتظار، کلید مجدداً وارد چرخه می‌شود.
- **مدیریت اتمام سهمیه (HTTP 403/402):** در صورتی که اعتبار یا سهمیه ماهانه یک اکانت به پایان برسد، از چرخه فعال خارج شده و ادامه درخواست‌ها با سایر اکانت‌ها انجام می‌پذیرد.
- **مدیریت کلید نامعتبر (HTTP 401):** کلید نامعتبر نشانه‌گذاری شده و پردازش به کلید بعدی منتقل می‌گردد.

### ۳. بخش اختصاصی افزودن و مدیریت کلیدها
- افزودن کلید به صورت تک‌تک با برچسب سفارشی.
- قابلیت **ورود دسته‌ای (Bulk Import)** برای جای‌گذاری همزمان ۶ کلید در یک کادر متنی.
- تست سلامت زنده (Ping Test) کلید پیش از ذخیره‌سازی.
- مشاهده تعداد درخواست‌های موفق هر کلید، آخرین زمان فراخوانی و لاگ خطاهای احتمالی.
- دکمه فعال/غیرفعال‌سازی موقت هر کلید و دکمه بازنشانی وضعیت در ابتدای ماه میلادی.

### ۴. استودیو نگارش مقاله علمی (Paper Writer Studio)
- نگارش فصول مقاله به زبان فارسی یا انگلیسی با سبک‌های استنادی **APA 7th**، **Vancouver** و **IEEE**:
  - عناوین پیشنهادی دانشگاهی
  - چکیده استاندارد (Abstract)
  - مقدمه و بیان مسئله (Introduction)
  - مروری بر متون و مبانی نظری (Literature Review)
  - ماتریس مقالات پژوهش (Literature Matrix)
  - مواد و روش‌های پژوهش (Methodology)
  - نتایج و بحث تطبیقی (Results & Discussion)
  - نتیجه‌گیری و پیشنهادات (Conclusion)
  - مراجع و رفرنس‌های کامل (References) با لینک مستقیم DOI
  - نگارش یکپارچه کل مقاله در یک فایل کامل
- ویرایشگر زنده دوطرفه با پیش‌نمایش فرمت‌بندی شده.
- شمارش آنلاین تعداد کلمات و مقالات استناد شده.

### ۵. خروجی‌های استاندارد
- **دانلود مستقیم فایل Word (.docx):** با فونت‌بندی علمی، راست‌چین استاندارد، جداول ماتریسی مرتب و ارجاعات درون‌متنی.
- **دانلود فایل Markdown (.md)**
- **خروجی مستقیم به کتابخانه EndNote:** با فرمت‌های استاندارد `.enw` و `.ris`.

## نحوه راه‌اندازی و استفاده

### روش اول: اجرای آسان با یک کلیک در ویندوز
روی فایل `run.bat` دو بار کلیک کنید. پنجره برنامه باز شده و مرورگر شما به صورت خودکار به آدرس زیر متصل می‌شود:
```
http://127.0.0.1:8000
```

### روش دوم: اجرا با دستور پایتون
در محیط ترمینال یا PowerShell در این پوشه، دستور زیر را اجرا نمایید:
```bash
python start.py
```

## نحوه وارد کردن کلیدهای API (۶ اکانت Consensus)

دو روش بسیار ساده برای وارد کردن کلیدها در نظر گرفته شده است:

### روش ۱: از طریق پنل کاربری نرم‌افزار (پیشنهادی)
1. برنامه را باز کرده و به تب **«🔑 مدیریت استخر کلیدها»** بروید.
2. در کادر **«ورود دسته‌ای کلیدها»**، ۶ کلید API خود را خط به خط قرار دهید و روی دکمه **«افزودن تمام کلیدها به بالانسر»** کلیک کنید.
3. یا با استفاده از فرم **«افزودن کلید جدید»**، کلیدها را با نام دلخواه (مثلاً *اکانت ۱ - جیمیل*) وارد کرده و روی «تست اتصال» و «ثبت» کلیک نمایید.

### روش ۲: از طریق ویرایش مستقیم فایل `consensus_keys.json`
می‌توانید فایل `consensus_keys.json` موجود در این پوشه را با یک ادیتور متنی باز کرده و کلیدهای دریافتی از [Consensus API Dashboard](https://consensus.app/api-mcp) را در فیلد `"key"` هر اکانت قرار دهید:
```json
{
  "id": "acc-1",
  "name": "اکانت شماره ۱",
  "key": "کلید_اکانت_اول_شما",
  "status": "active"
}
```

## حالت آزمایشی (Demo Mode)
در صورتی که هنوز کلیدهای خود را دریافت نکرده‌اید یا می‌خواهید بدون مصرف سهمیه اکانت‌های خود، کارکرد نگارش مقاله، بالانسر و خروجی Word را تست کنید، کافیست در بالای صفحه روی دکمه **«🧪 حالت آزمایشی»** کلیک کنید. در این حالت مقالات نمونه و رفتار سیستم به صورت شبیه‌سازی‌شده عمل خواهند کرد.
